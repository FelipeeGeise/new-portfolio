# Portfólio – Felipe Thiago

Next.js (App Router) + CSS puro.

## Rodar
```bash
npm install
npm run dev   # http://localhost:3000
```

## Personalize
- Textos, skills, projetos e links: `app/page.js` (objetos `skills`, `projects`, `links`).
- Currículo: coloque seu PDF em `public/curriculo.pdf`.
- Imagens dos projetos: `public/projetos/havihannah.jpg`, `confeitaria.jpg`, `imobiliaria.jpg`.
- Cores: variáveis no topo de `app/globals.css`.

## Deploy
Suba para o GitHub e importe o repositório na Vercel.
